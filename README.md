**Folio — Responsive Profile Page UI/UX**

A modern, responsive profile page design for Folio, a fictional professional portfolio platform.

**Project Overview**

Designed as part of the Pynexia Technology UI/UX Design Internship — Week 1.

**Features**

- Responsive Desktop, Tablet, and Mobile layouts.
- Professional profile header with avatar and biography.
- Profile statistics and navigation tabs.
- About Me, Skills, and Contact Information.
- Featured Projects with visual previews.
- Work Experience and Education sections.
- Consistent typography, colours, and spacing across devices.

**Design System**

- Primary: "#5146D8"
- Secondary: "#E3E1FC"
- Background: "#F8F9FC"
- Typography: Inter
- Design tool: Figma
